# 업무 내비게이터 (관리자 테스트용 · AI 연결 허용)

업무별 체크리스트·마감일·보고서·서식·법령 자료를 한곳에서 관리하는 **업무 도우미 프로그램**의 **관리자 테스트용 버전**입니다.
배포용 버전과 기능은 같고, **AI 연결 설정(Gemini·ChatGPT·Claude API 키 입력)이 열려 있다**는 점만 다릅니다.

- 현재 버전: **v1.1.0** (2026-10-07)
- 배포용(AI 연결 설정 차단) 버전: [Work_Navigator_off](https://github.com/koo2957-collab/Work_Navigator_off)

> ⚠️ **관리자 전용입니다.** 사내 보안 정책상 일반 사용자에게는 배포용 버전을 배포하세요.
> 이 버전은 화면 제목에 `[TEST - 관리자 전용]`이 표시됩니다.

## 배포용과의 차이

| 항목 | 배포용 (Work_Navigator_off) | 이 저장소 (ainav_final) |
| --- | --- | --- |
| AI 연결 설정 화면 | 보안 정책 안내만 표시, 입력 UI 숨김 | API 키 입력 UI 표시 |
| AI 기능 (체크리스트·보고서·길잡이·업무파트너 생성) | 사용 불가 | API 키를 등록하면 사용 가능 |
| 화면 제목 | 업무 내비게이터 | 업무 내비게이터 [TEST - 관리자 전용] |
| 그 밖의 기능 | 같음 | 같음 |

## 시작하기

1. 이 저장소를 내려받습니다. (초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기)
2. `index.html`과 `vendor` 폴더가 **같은 폴더 안에** 있는지 확인합니다.
3. `index.html`을 **Chrome** 또는 **Edge**로 엽니다.

> `vendor` 폴더가 없으면 글꼴, PDF 미리보기, Word 문서 읽기가 동작하지 않습니다.

## AI 연결하기

1. **설정 → 환경설정… → AI 연결** 탭을 엽니다.
2. AI 서비스(Gemini·ChatGPT·Claude)를 고르고 API 키를 붙여 넣은 뒤 **연결 테스트**를 누릅니다.
   - Gemini 키는 [Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료로 발급받을 수 있습니다.
3. 연결되면 헤더에 연결 상태가 표시되고, AI 기능을 쓸 수 있습니다.

> API 키는 이 PC의 브라우저 저장 공간에만 보관됩니다. 공용 PC에서는 테스트가 끝난 뒤 키를 지우세요.
> AI 기능을 쓰면 업무 내용이 선택한 AI 서비스(해외 서버)로 전송됩니다. 민감한 자료로는 테스트하지 마세요.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 프로그램 본체 (파일 하나로 동작) |
| `vendor/` | 프로그램이 사용하는 글꼴(Pretendard)과 PDF·Word 문서를 읽는 도구 |

## 내 자료는 어디에 저장되나요?

- 업무 자료와 설정은 프로그램 파일이 아니라 **브라우저 안의 저장 공간**에 저장됩니다. 새 버전 파일로 바꿔도 그대로 남습니다.
- 다른 브라우저나 PC로 옮길 때는 **설정 → 백업 및 복원**에서 백업 파일을 만들어 옮기세요.
- 배포용과 테스트용을 **같은 브라우저로 열면 자료를 함께 씁니다.** 파일을 PC에서 바로 열 때는 폴더가 달라도 같은 저장 공간을 쓰기 때문입니다.
  테스트 자료가 섞이지 않게 하려면 **다른 브라우저**(예: 평소에는 Chrome, 테스트는 Edge)나 **별도 브라우저 프로필**에서 여세요.

## 주요 기능

- **업무 관리**: 상태 탭(전체·진행중·레퍼런스·처리완료·보관함), 폴더, 끌어다 놓기로 이동, 휴지통
- **체크리스트**: 「단계 + 할 일」 구조, 건너뛰기, 「해당 없음」 처리, 항목별 마감일
- **재사용 업무·레퍼런스**, **보고서 작성·관리**, **서식·문서함**(HWPX·PDF·Word 미리보기)
- **법령·매뉴얼 자료실**: AI 연결 시 답변의 참고 자료로 활용 (Gemini 연결 시 의미 검색용 임베딩 자동 처리)
- **AI 기능**: AI 체크리스트 생성, AI 보고서 생성, AI 길잡이(업무 단계 안내), AI 업무파트너(챗봇)
- **알림센터**: 확인이 필요한 알림만 숫자로 표시, 알림을 누르면 관련 화면으로 이동, 같은 알림은 1건으로 유지
- **공유·내보내기·가져오기**, **통계 대시보드**, **다크 / 라이트 모드**

## 관리자 참고

- 이 파일과 [Work_Navigator_off](https://github.com/koo2957-collab/Work_Navigator_off)의 `index.html`은 **AI 연결 설정 영역 두 곳과 제목만 다릅니다.** 기능을 고칠 때는 두 저장소에 똑같이 반영하세요.
  - 보안 정책 안내 블록: 이 버전에서는 `display:none` (숨김)
  - AI 입력 UI 블록: 이 버전에서는 표시 (배포용은 `display:none`)
- 버전을 올릴 때는 `APP_VERSION`, `APP_RELEASE_DATE`, `APP_RELEASE_NOTES` 세 가지를 고칩니다. 기능 추가는 가운데 숫자, 오류 수정만 할 때는 끝 숫자를 올립니다.
